# Quaterm 仕様書 (試作版)

Quaterm は、ホットキーを押すと画面の上端または下端からスルッと出てくる macOS 用ターミナルである。
端末の中身は libghostty で描画し、それ以外のウィンドウ・タブ・環境設定は Swift と AppKit で作る。

## 目的とスコープ

iTerm2 のホットキーウィンドウを置き換える。描画を速くし、機能は日常で使うものに絞る。

**スコープ外**: 画面分割、マウスでの縁ドラッグによるサイズ変更、テーマの設定画面、プロファイル機能。

## 技術構成

| 部品 | 採用するもの | 役割 |
|---|---|---|
| 言語・UI | Swift、AppKit | ウィンドウ、タブ、環境設定、メニューバー |
| 端末エンジン | libghostty (`ghostty.h` の埋め込み API) | 端末の解釈、Metal による描画、入力処理 |
| libghostty の導入 | `libghostty-spm` (非公式の Swift パッケージ) | Zig のビルド環境なしで組み込む |
| グローバルホットキー | `KeyboardShortcuts` (sindresorhus) | システム全体のキー監視、キー登録用の画面部品 |
| 通知 | `UserNotifications` (macOS 標準) | コマンド終了の通知 |

> [!WARNING] libghostty の API は安定版ではない
> 公式ドキュメントは、埋め込み API を「Ghostty の macOS アプリ専用で、汎用 API ではない」としている。
> 使う libghostty のバージョンを固定し、上げるときは動作確認をしてから上げる。

## ウィンドウ

### 見た目

- タイトルバーと信号ボタン (閉じる・最小化・拡大の 3 色ボタン) は付けない
- 横幅は、表示するディスプレイの幅いっぱいにする
- 縦幅は画面の高さに対する割合で決める。既定は 40%、範囲は 20〜100% とする
- メニューバーと重ならない位置に出す

### 出し方と隠し方

- 呼び出しキーを押すと、ウィンドウが出る。もう一度押すと隠れる
- ウィンドウが出ている間は Quaterm が前面のアプリになり、メニューバーも Quaterm のものになる。隠すと、直前に使っていたアプリが前面に戻る
- 出てくる方向は「上から」「下から」の 2 択とする
- アニメーションの速さを環境設定で変えられる。フェード (透明度の変化) の有無も選べる
- フルスクリーンのアプリの上や、どのデスクトップ (Space) からでも呼び出せる

### ピン留め

| 状態 | ほかのアプリのウィンドウをクリックしたとき | 表示の重なり順 |
|---|---|---|
| オフ | ターミナルが自動で隠れる | 最前面 (スクリーンセーバーより下) |
| オン | 隠れずに表示し続ける | 最前面 (スクリーンセーバーより下) |

ピン留め中に隠すときは、呼び出しキーを押す。
Quaterm の環境設定ウィンドウをクリックしても、ターミナルは隠れない。

### サイズ変更

- 「伸ばす」キーと「縮める」キーを用意する。1 回押すごとに画面の高さの 5% ずつ変える
- 上から出す設定のときは下端が動く。下から出す設定のときは上端が動く
- 下から出す設定のときは、「伸ばす」キーで縮み、「縮める」キーで伸びる。キーを矢印にしたときに、矢印の向きと端の動く向きをそろえるためである
- キーで変えた高さは保存し、次に呼び出したときも同じ高さで出す

### 表示するディスプレイ

環境設定で次の 3 つから選ぶ。

| 設定 | 表示先 |
|---|---|
| メインディスプレイ | macOS の設定でメインにしているディスプレイ |
| アクティブなディスプレイ | マウスカーソルがあるディスプレイ |
| 指定したディスプレイ | 環境設定のリストで選んだディスプレイ |

「指定したディスプレイ」を選んだ状態でそのディスプレイが外された場合は、次に呼び出したときにダイアログを出す。
ダイアログでは「メイン」「アクティブ」のどちらに出すかを選ばせ、選んだ結果を保存する。キャンセルした場合は、今回だけアクティブなディスプレイに表示し、次に呼び出したときにもう一度たずねる。
保存した結果は、環境設定からあとで変更できる。

## タブ

- `Command+T` で新しいタブを開き、`Command+W` で今のタブを閉じる
- タブには X ボタンを付ける。X ボタンはマウスを乗せたタブにだけ表示する
- 最後のタブを `Command+W` か X ボタンで閉じるときは、確認ダイアログを出す。シェルが自分で終了した (`exit` など) ときは確認しない
- 確認ダイアログには「次回から表示しない」のチェックボックスを付ける。環境設定の「最後のタブを閉じるときに確認する」と同じ設定値を読み書きする
- 最後のタブを閉じた場合は、ウィンドウを隠す。次に呼び出したときは新しいタブを 1 つ開いた状態で出す
- タブバーの位置は「上」「下」「出てくる方向に合わせる」から選ぶ。既定は「上」とする。「出てくる方向に合わせる」では、上から出すときは上、下から出すときは下に置く
- タブバーは自作する。libghostty が提供するのは 1 画面分の端末 (surface) だけである

## キーバインド

すべて環境設定で変更できる。既定のキーは仮の値であり、実装時に他アプリとの衝突を確認して決める。

| 操作 | 既定のキー (仮) | 効く範囲 |
|---|---|---|
| 表示・非表示の切り替え | ``Control+` `` | システム全体 |
| ピン留めの切り替え | `Command+Shift+P` | ターミナルが前面にあるときだけ |
| 新しいタブ | `Command+T` | ターミナルが前面にあるときだけ |
| タブを閉じる | `Command+W` | ターミナルが前面にあるときだけ |
| ウィンドウを伸ばす | `Command+Option+=` | ターミナルが前面にあるときだけ |
| ウィンドウを縮める | `Command+Option+-` | ターミナルが前面にあるときだけ |
| 文字を大きくする | `Command+Shift+;` (JIS 配列の刻印では `Command+Shift++`) | ターミナルが前面にあるときだけ |
| 文字を小さくする | `Command+Shift+-` | ターミナルが前面にあるときだけ |
| 半透明の切り替え | `Command+U` | ターミナルが前面にあるときだけ |

次のキーは固定で、変更できない。

| 操作 | キー |
|---|---|
| 環境設定を開く | `Command+,` |
| 終了 | `Command+Q` |

文字の大きさは、今開いているタブだけに効く。新しいタブは既定の大きさで開く。
半透明は、背景の不透明度を環境設定のスライダーの値 (20〜95%、既定 80%) にする。オン・オフは保存され、環境設定の「背景を半透明にする」とも同期する。

システム全体で監視するのは「表示・非表示の切り替え」だけとする。
ほかのキーもシステム全体で監視すると、`Command+T` などがブラウザでも奪われて効かなくなるためである。

## コマンド終了の通知

### 仕組み

シェルは、コマンドが終わってプロンプトに戻った瞬間に、OSC 133 という規格の合図を画面へ送る。
libghostty はこの合図を受け取り、`GHOSTTY_ACTION_COMMAND_FINISHED` というイベントでアプリに知らせる。
イベントには `exit_code` (0〜255、不明なら -1) と `duration` (実行時間、ナノ秒) が入っている。

### 通知を出す条件

次の 3 つをすべて満たしたときだけ通知する。

1. ウィンドウが隠れている
2. コマンドの実行時間が、設定した秒数以上である。既定は 10 秒
3. 結果が「通知する結果」の設定に合っている。設定は「常に」「失敗時のみ」の 2 択で、既定は「常に」

### 通知の文面

- 返り値が 0 のときは「成功」と、実行時間を出す
- 返り値が 0 以外のときは「失敗 (返り値 N)」と、実行時間を出す

## アプリ全体

- どの確認ダイアログも、Esc キーでキャンセルできる

- Dock にアイコンを出すかどうかを環境設定で選べる
- メニューバーには常駐アイコンを置く。Dock 非表示でも、ここから環境設定を開ける
- 環境設定ウィンドウは HIG のパネルと同じ扱いにする。ターミナルと同じ重なり順に置き、後から前面に出したほうが手前に来る。Quaterm 以外のアプリが前面になると隠れ、Quaterm に戻ると再び表示される
- 終了するときは、`Command+Q` とメニューの「終了」のどちらでも確認ダイアログを出す
- 確認ダイアログには「次回から表示しない」のチェックボックスを付ける。環境設定の「終了時に確認する」と同じ設定値を読み書きする
- 確認ダイアログは、ピン留めの有無にかかわらず、ターミナルより手前に出す

## フォント

環境設定の「フォント」で、フォントの種類と大きさを決める。種類は、インストール済みの等幅フォントから選ぶ。既定は Ghostty 内蔵のフォントで、大きさは 14 pt (範囲 6〜72 pt) とする。
変更は開いている全タブに反映する。ただし、文字を大きく・小さくするキーで大きさを変えたタブは、そのタブで変えた大きさのままにする。

## 環境設定の一覧

環境設定は HIG の設定ウィンドウの形にする。ツールバーに「一般」「ショートカット」「ウィンドウ」「ディスプレイ」「フォント」「ターミナル」「通知」の 7 つの分類を並べ、選んだ分類だけを表示する。
ウィンドウのタイトルは表示中の分類名にし、次に開いたときは前回の分類を表示する。

| 項目 | 種類 | 既定値 |
|---|---|---|
| Dock にアイコンを表示する | チェックボックス | オン |
| 各キーバインド | キー登録欄 | キーバインドの表を参照 |
| スクロールバックの保持量 | 数値 | 10000 行相当 |
| 出てくる方向 | 上から / 下から | 上から |
| タブの位置 | 上 / 下 / 出てくる方向に合わせる | 上 |
| アニメーションの速さ | スライダー | 0.2 秒 |
| フェードを入れる | チェックボックス | オフ |
| 選択しただけでコピーする | チェックボックス | オフ |
| 表示するディスプレイ | メイン / アクティブ / 指定 | アクティブ |
| 指定するディスプレイ | 接続中ディスプレイのリスト | なし |
| 指定ディスプレイが外れたときの表示先 | メイン / アクティブ | 未設定 (初回にダイアログで決める) |
| 縦幅 | 割合 (20〜100%) | 40% |
| 通知する最短の実行時間 | 秒数 | 10 秒 |
| 通知する結果 | 常に / 失敗時のみ | 常に |
| 終了時に確認する | チェックボックス | オン |
| 最後のタブを閉じるときに確認する | チェックボックス | オン |
| フォント | 等幅フォントの一覧 | Ghostty 内蔵 |
| フォントの大きさ | 数値 (6〜72 pt) | 14 pt |
| 背景を半透明にする | チェックボックス | オフ |
| 半透明時の不透明度 | スライダー (20〜95%) | 80% |

## 調査結果 (旧・未確認事項)

実装前に確かめた結果と、仕様への反映内容をまとめる。
確かめた手段は、ライブラリのソースコード (libghostty-spm 2.2.2026112303、Ghostty コミット `56de3f0f`、KeyboardShortcuts 1.10.0) を読んだことである。

| 項目 | 結果 | 仕様への反映 |
|---|---|---|
| スクロールバックの単位 | Ghostty 1.4 で行数指定の `scrollback-limit-lines` が追加されている | 行数でそのまま指定する。バイト数上限 `scrollback-limit-bytes` は行数 × 16 KB に引き上げる |
| 通知へのコマンド名の表示 | コマンド終了のイベントは返り値と実行時間だけを持つ | 通知にコマンド名は出さない |
| シェル統合の自動適用 | libghostty-spm は bash と zsh 用のシェル統合を同梱し、`.exec` で起動すると自動で入れる | zsh・bash では設定不要。fish などほかのシェルは対象外 |
| `libghostty-spm` の対応状況 | コマンド終了 (`TerminalSurfaceCommandFinishedDelegate`) を Swift から受け取れる | Zig での自前ビルドは不要 |
| ホットキーの権限 | KeyboardShortcuts は Carbon の `RegisterEventHotKey` を使う | アクセシビリティ権限は求めない。実機での確認は未実施 |
| ローカル用ショートカットの扱い | KeyboardShortcuts は、名前を付けたショートカットをすべてシステム全体に登録する | 起動時と変更時に、ローカル用の登録を解除する。ローカル用に呼び出しキーと同じキーを割り当てた場合は解除しない |

## 受け入れ条件

- [ ] 別のアプリが前面にあるときに呼び出しキーを押すと、ターミナルが出てくる
- [ ] 上から・下からの両方で、設定した速さのアニメーションで出入りする
- [ ] ピン留めオフで別ウィンドウをクリックすると、ターミナルが隠れる
- [ ] ピン留めオンで別ウィンドウをクリックしても、ターミナルが最前面に残る
- [ ] `Command+T` でタブが増え、`Command+W` と X ボタンでタブが閉じる
- [ ] 最後のタブを閉じるとウィンドウが隠れ、次の呼び出しで新しいタブが 1 つ開いている
- [ ] 最後のタブを `Command+W` で閉じると確認ダイアログが出る。「次回から表示しない」を選ぶと出なくなり、環境設定で元に戻せる
- [ ] `Command+Shift++` と `Command+Shift+-` で、今のタブの文字が大きく・小さくなる
- [ ] `Command+U` で背景が半透明になり、もう一度押すと元に戻る
- [ ] ターミナルが前面にあるときに `Command+,` で環境設定が開く
- [ ] 伸ばす・縮めるキーで高さが 5% ずつ変わり、次の呼び出しでも同じ高さで出る
- [ ] ウィンドウを隠した状態で `sleep 11; false` を実行すると、「失敗 (返り値 1)」の通知が出る
- [ ] 指定したディスプレイを外して呼び出すと、表示先を選ぶダイアログが出る
- [ ] Dock 非表示でも、メニューバーのアイコンから環境設定を開ける
- [ ] 「次回から表示しない」を選ぶと終了確認が出なくなり、環境設定で元に戻せる
